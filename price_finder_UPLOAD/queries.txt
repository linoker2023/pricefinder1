# Список товаров для поиска и мониторинга — по одному на строку.
# Формат: товар ; желаемая цена ; падение в % ; сайты через запятую
# Прочерк «-» = поле не задано. Строки с # и пустые игнорируются.
#
# Запуск:
#   python price_finder.py search --queries-file       # найти цены по всему списку
#   python price_finder.py watch  --queries-file -i 30m # следить за ценами
#
# Примеры (уберите # и впишите свои товары):
# iphone 15 128gb ; 60000
# ноутбук asus vivobook 15 ; 45000 ; 5
# кофемашина delonghi magnifica ; 25000 ; 7 ; bookvoed
# наушники sony ; - ; - ; bookvoed
