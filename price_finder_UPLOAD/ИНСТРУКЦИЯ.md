# Подробная инструкция по запуску pricefinder

Здесь пошагово: установка → первый запуск → **где указывать товар** → мониторинг цен →
подключение своих сайтов → решение проблем.

* **На телефоне (Android)** программа запускается так же — подробная инструкция в
  **[android/ANDROID.md](android/ANDROID.md)** (Termux, Pydroid 3, сенсорный
  интерфейс и сборка APK). Раздел [10](#10-запуск-на-android-кратко) — короткая версия.

---

## 0. Три способа указать товар

| Способ | Где вводить | Когда удобно |
|---|---|---|
| **1. В команде** | `python price_finder.py search "iphone 15 128gb"` | разово посмотреть цену |
| **2. В файле `queries.txt`** ⭐ | обычный блокнот, по одному товару на строку | список товаров, мониторинг, можно править без знания команд |
| **3. В базе (цели)** | `python price_finder.py targets add "кофемашина" --target-price 25000` | постоянный «сторож» цены, который живёт между запусками |

Способ 2 — основной: он описан в разделе [3](#3-где-указывать-товар-queriestxt).

## 1. Установка

### 1.1. Windows

1. Установите **Python 3.10 или новее**: <https://www.python.org/downloads/>.
   В первом окне установщика **обязательно** поставьте галочку
   **`Add python.exe to PATH`** → `Install Now`.
2. Скопируйте папку `price_finder` в удобное место, например `C:\price_finder`.
3. **Двойной клик по `setup.bat`** — создастся окружение `.venv` и установятся библиотеки.

   Или вручную: нажмите `Win+R`, введите `cmd`, Enter, затем:
   ```bat
   cd /d C:\price_finder
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```

### 1.2. Linux

```bash
cd price_finder
bash setup.sh
```

или вручную:

```bash
sudo apt install python3 python3-venv python3-pip     # Debian/Ubuntu
cd price_finder
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 1.3. macOS

```bash
brew install python        # если Python ещё нет
cd price_finder
bash setup.sh
```

### 1.4. Проверка, что всё встало

```bash
python price_finder.py --version        # Windows
python3 price_finder.py --version       # Linux/macOS
# ожидаемый ответ: pricefinder 1.0.0
```

> Дальше в примерах используется `python`. В Linux и macOS пишите `python3`
> (или активируйте окружение — тогда работает и `python`).

### 1.5. Необязательно: браузер для JS-сайтов

Нужен только для площадок, которые рисуют цены скриптами (Ozon, Wildberries, Яндекс.Маркет):

```bash
pip install playwright
playwright install chromium
```

## 2. Первый запуск (проверка без интернета)

В комплекте локальный демо-магазин, чтобы убедиться, что программа работает.

**Терминал 1** — поднимаем магазин:

```bash
python price_finder.py serve-demo
```

**Терминал 2** — ищем товар:

```bash
python price_finder.py search "ноутбук"
```

Должна появиться таблица, отсортированная от дешёвого к дорогому:

```
  Самые низкие цены: «ноутбук»
  Предложений: 8 · минимум 22 991 ₽ · медиана 34 261 ₽ · разброс 260.1%

№              Цена       Выгода   Товар                        Площадка               Ссылка
───────────────────────────────────────────────────────────────────────────────────────────────
1.            22 991 ₽         −33%   Ноутбук HP 15s-eq2000, 8 …   ДемоМаркет-2 (дешев…   127.0.0.1:8765/product/4
2.            24 990 ₽         −27%   Ноутбук HP 15s-eq2000, 8 …   ДемоМаркет (локальн…   127.0.0.1:8765/product/4
...
```

Что означают колонки:

* **Цена** — в базовой валюте (`settings.currencies.base`, по умолчанию ₽);
* **Выгода** — насколько это дешевле/дороже медианы выборки (`−33%` = на треть дешевле средней);
* **Площадка** — где найдено; `+1` означает «такая же цена есть ещё на одной площадке»;
* **Ссылка** — кликабельный адрес предложения.

Одной командой весь демо-сценарий (поиск → фильтры → мониторинг → история):

```bash
bash run_demo.sh        # Linux/macOS
```

## 3. Где указывать товар: `queries.txt`

Это обычный текстовый файл рядом с программой. Создайте его:

```bash
python price_finder.py init-queries
```

Откройте `queries.txt` в блокноте (Windows: правый клик → «Открыть с помощью» → Блокнот)
и впишите свои товары — **по одному на строку**:

```text
# Формат:  товар ; желаемая цена ; падение в % ; сайты через запятую
iphone 15 128gb ; 60000
ноутбук asus vivobook 15 ; 45000 ; 5
кофемашина delonghi magnifica ; 25000 ; 7 ; bookvoed
наушники sony wh-1000xm5 ; - ; - ; bookvoed
робот-пылесос xiaomi
```

Правила:

* всё, кроме названия товара, **необязательно**;
* `; желаемая цена` — искать только предложения не дороже этой суммы (в `search`)
  и присылать уведомление при её достижении (в `watch`);
* `; падение в %` — уведомлять, когда цена упала на N% с прошлой проверки;
* `; сайты` — ограничить список площадок для этой строки (id через запятую);
* прочерк `-` означает «поле не задано» (нужно, чтобы дойти до списка сайтов);
* строки, начинающиеся с `#`, и пустые — игнорируются;
* разделитель `;` можно заменить на `|`.

Запуск по всему списку:

```bash
python price_finder.py search --queries-file            # найти цены по всем товарам
python price_finder.py search -f queries.txt --top 10   # то же, короткая форма
python price_finder.py search -f мой_список.txt         # свой файл
python price_finder.py watch  --queries-file -i 30m     # следить за всеми товарами
```

Для Windows есть кнопки без терминала:

| Файл | Что делает |
|---|---|
| `setup.bat` | установка (один раз) |
| `search.bat` | открывает `queries.txt` (если пуст), ищет цены по списку, сохраняет `out\results.xlsx` |
| `watch.bat` | мониторинг списка каждые 30 минут |

Аналоги для Linux/macOS: `bash setup.sh`, `bash search.sh`, `bash watch.sh [интервал]`.

### 3.1. Как писать запрос, чтобы находилось нужное

| Плохо | Хорошо | Почему |
|---|---|---|
| `телефон` | `смартфон samsung galaxy a55 256gb` | слишком общее — будет шум |
| `"iphone 15"` (с кавычками внутри файла) | `iphone 15` | в `queries.txt` кавычки не нужны |
| `Ноутбук ASUS` | `ноутбук asus vivobook 15 x515` | регистр не важен, важна конкретика |
| `корм` | `корм для кошек royal canin 2 кг` | бренд + фасовка убирают лишнее |

В **командной строке** запрос с пробелами берите в кавычки:

```bash
python price_finder.py search "корм для кошек royal canin"
```

Дополнительно сузить выдачу (флаги работают и со списком, и с одним товаром):

```bash
python price_finder.py search "iphone 15" ^
    --min-price 20000 --max-price 90000 ^   # ценовой коридор
    --exclude "б/у" "витрина" "уценённый" ^ # убрать мусор
    --include "128gb" ^                     # оставить только нужное
    --require-keyword ^                     # в названии обязаны быть слова запроса
    --in-stock ^                            # только в наличии
    --max-ratio 1.5                         # не показывать дороже «минимум × 1.5»
```

## 5. Мониторинг цен и уведомления

### 5.1. Запустить вручную

```bash
# один товар: проверка каждые 30 минут, сигнал при цене ниже 45 000 ₽ или падении на 5%
python price_finder.py watch "playstation 5" --interval 30m --target-price 45000 --drop-pct 5

# весь список queries.txt (пороги берутся из строк файла)
python price_finder.py watch --queries-file --interval 30m

# один прогон и выход (удобно для планировщика задач / cron)
python price_finder.py watch --queries-file --once
```

Интервалы: `30m`, `2h`, `1d`, `900` (секунды).

### 5.2. Постоянные цели в базе

```bash
python price_finder.py targets add "кофемашина" --target-price 25000 --drop-pct 5
python price_finder.py targets add "пылесос" --sites bookvoed --target-price 20000
python price_finder.py targets list
python price_finder.py watch -i 2h          # следит за всеми целями из базы
python price_finder.py targets remove 2
```

### 5.3. Когда придёт уведомление

* цена стала **не выше** `--target-price` (или порога из `queries.txt`);
* цена — **минимум за всё время наблюдений** (исторический минимум);
* цена упала на **N%** с прошлой проверки (`--drop-pct`).

Повторы подавляются: одно событие не шлётся дважды, а «цена ниже цели» — не чаще
раза в `--alert-cooldown` часов (по умолчанию 6).

### 5.4. Telegram (проще всего)

4. Впишите в `config/sites.yaml`:

### 5.6. Запуск по расписанию (чтобы не держать окно открытым)

**Windows — Планировщик заданий** (Действие → «Создать задачу» → триггер «Ежедневно, каждые 2 часа»,
действие — запуск программы):

```
Программа:  C:\price_finder\.venv\Scripts\python.exe
Аргументы:  price_finder.py watch --queries-file --once
Рабочая папка: C:\price_finder
```

**Linux — cron** (`crontab -e`):

```cron
0 */2 * * * cd /home/user/price_finder && .venv/bin/python price_finder.py watch --queries-file --once >> watch.log 2>&1
```

**Linux — systemd-сервис** (`/etc/systemd/system/pricefinder.service`):

```ini
[Unit]
Description=pricefinder watch
After=network-online.target

[Service]
WorkingDirectory=/home/user/price_finder
ExecStart=/home/user/price_finder/.venv/bin/python price_finder.py watch --queries-file -i 30m
Restart=always
RestartSec=60

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now pricefinder
```

## 6. Подключение своего сайта

Откройте `config/sites.yaml` в блокноте и добавьте блок (шаблон `my-shop` уже внутри):

```yaml
  - id: myshop
    name: Мой магазин
    enabled: true
    search_url: "https://myshop.ru/search?q={query}&sort=price&page={page}"
    product_selector: "div.product-card"      # контейнер одной карточки
    fields:
      title: ".product-card__title"
      price: ".product-card__price"
      old_price: "max:.price-old"
      url: "a.product-card__link"             # сам возьмёт href
      image: "img.product-card__img"          # сам возьмёт src
      seller: ".seller"
      availability: ".stock"
    currency: RUB
    max_pages: 2
    delay: 1.5
    min_price: 10
    exclude_keywords: ["б/у", "витрина"]
```

**Самый быстрый путь — вообще не писать селекторы.** Оставьте только `search_url`:
программа сама попробует найти карточки по микроразметке JSON‑LD / microdata / meta-тегам.

**Как узнать селекторы самому:** откройте сайт → F12 (инструменты разработчика) →
кликните на карточку товара → в коде справа найдите общий контейнер карточек →
скопируйте его класс (`div.product-card`) и классы названия/цены.

Проверка одной командой:

```bash
python price_finder.py test-site myshop "запрос" --sample 5 --dump-html page.html
```

Вывод покажет HTTP-код, размер страницы, сработавшую стратегию и первые карточки.

## 7. Где что лежит

| Путь | Что это |
|---|---|
| `price_finder.py` | сама программа (все консольные команды) |
| `gui_app.py` | сенсорный интерфейс (`python price_finder.py gui`) |
| `queries.txt` | **ваш список товаров** |
| `android/` | установка и запуск на телефоне: скрипты, планировщик, сборка APK, `ANDROID.md` |
| `config/sites.yaml` | сайты, валюты, Telegram/SMTP |
| `price_finder.db` | история цен, цели, журнал уведомлений (создаётся автоматически) |
| `out/` | сохранённые отчёты: `.xlsx`, `.csv`, `.html`, `.json` |
| `tests/demo_server.py` | локальный демо-магазин |
| `tests/test_all.py` | 23 теста ядра: `python tests/test_all.py` |
| `tests/test_gui.py` | 20 тестов мобильной части: `python tests/test_gui.py` |

История цен не теряется между запусками: каждый `search` (кроме `--no-history`)
дописывает наблюдения в `price_finder.db`, поэтому `history` и «исторический минимум»
работают только при регулярных запусках.

## 8. Если что-то не так

| Симптом | Решение |
|---|---|
| `'python' не является внутренней или внешней командой` | Python без PATH: переустановите с галочкой `Add python.exe to PATH` или используйте `.venv\Scripts\python.exe price_finder.py ...` |
| `ModuleNotFoundError: requests` | не активировано окружение: `pip install -r requirements.txt` (Windows: `.venv\Scripts\activate`) |
| `HTTP 403 / 429 / 503` | сайт видит бота: добавьте `js_render: true`, увеличьте `delay`, укажите свои `cookies`/`headers`, используйте прокси |
| «карточки не распознаны» | не те селекторы или контент грузит JS: `test-site <id> "q" --dump-html p.html`, затем правьте `fields` |
| `robots.txt disallow` | сайт запрещает парсинг каталога; обход — `--ignore-robots` (на вашу ответственность) |
| `нужен Playwright` | `pip install playwright && playwright install chromium` |
| результатов много, но все не те | `--require-keyword`, `--exclude`, `--include`, `--max-ratio 1.5`, `--in-stock` |
| цены в $ и € сравниваются странно | `--update-rates` или пропишите курсы в `settings.currencies.rates` |
| не приходят уведомления | заполнены ли `settings.telegram` / `settings.smtp`; не сработал ли `--alert-cooldown` |
| ничего не находится в демо | поднят ли демо-магазин: `python price_finder.py serve-demo` |

## 10. Запуск на Android (кратко)

Полная версия — в [android/ANDROID.md](android/ANDROID.md).
**Нужен именно APK-файл?** Его надо собрать (готового в проекте нет):
самый простой способ — бесплатная сборка в облаке GitHub за 20–40 минут,
инструкция в [APK.md](APK.md).

```bash
# 1. Termux из F-Droid, затем:
cd ~/price_finder
bash android/install_termux.sh          # python + requests + beautifulsoup4

# 2. проверка
source .venv/bin/activate
python price_finder.py env

# 3. товар — так же, как на ПК
python price_finder.py search "iphone 15"
python price_finder.py init-queries && nano queries.txt
python price_finder.py search --queries-file

# 4. мониторинг по расписанию (Termux можно закрыть)
pkg install termux-api                  # + приложение «Termux:API» из F-Droid
bash android/setup_termux_job.sh 30m

# 5. сенсорный интерфейс
bash android/install_gui_termux.sh
termux-x11 :1 -ac & export DISPLAY=:1
python price_finder.py gui

# всё сразу в одном меню
bash android/termux_start.sh
```

На телефоне данные лежат в `~/pricefinder/` (база цен, отчёты, список товаров) —
точный путь показывает `python price_finder.py env`.

## 11. Важное напоминание

* Цена в выдаче может отличаться от цены в корзине (регион, скидка по карте, доставка) —
  финальная проверка по ссылке.
* Не долбите сайты частыми запросами: держите `delay` 1–3 секунды и не запускайте
  `watch` чаще, чем раз в 15–30 минут.
* Перед автоматизацией проверьте условия использования сайта и его `robots.txt`
  (по умолчанию программа его уважает).
